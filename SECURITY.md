# 安全策略 / Security Policy

如果你发现了安全问题（例如绕过口令或管理员认证、越权访问其他账本、OAuth / MCP 授权缺陷），请不要公开提 Issue，而是通过 GitHub 的 [Report a vulnerability](https://github.com/LYJW131/aapay/security/advisories/new) 私下报告，并尽量附上复现步骤与影响范围。我会尽快确认并修复，修复发布后再公开细节。

If you find a security issue (for example bypassing passcode or admin authentication, accessing another ledger, or flaws in OAuth / MCP authorization), please don't open a public issue. Report it privately via GitHub's [Report a vulnerability](https://github.com/LYJW131/aapay/security/advisories/new) with reproduction steps and impact. Fixes are released before details are made public.

只有 `main` 分支的最新版本会收到安全修复。Only the latest version on `main` receives security fixes.
